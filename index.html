LOCAL • NO ACCOUNT • NO CLOUD SERVER

Someone's at the door.

Pair two phones once using an invite and answer code. After pairing, Ring sends an alert to the other phone, and you can start a two-way camera and microphone call over your local network.

Both phones need this page open on the same Wi‑Fi (not a guest or isolated network). Pair once with copy/paste codes: invite from the doorbell phone, answer from the indoor phone. Camera and microphone only work when the page is opened from https://, localhost, or a local file your browser treats as secure. If a call says the camera is blocked, host this file on a local web server.

1 · Choose your phone's role

2 · Pair the two phones

On the doorbell phone, create an invite and send its code to the indoor phone. The indoor phone makes an answer code and sends it back. Finally paste the answer on the doorbell phone.

Pairing code may be long. Use Copy, switch phones, paste it in the other phone, and repeat. Keep both pages open while pairing.
